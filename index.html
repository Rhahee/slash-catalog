Prompt gambar untuk ChatGPT

Pilih shorthand berdasarkan gaya gambar yang ingin dibuat. Setiap entri berisi prompt lengkap dan contoh visual.

Kode seperti /metaads adalah singkatan prompt komunitas, bukan command resmi. Tombol salin menyalin instruksi lengkapnya.

Cara menggunakan katalog

  1. Pilih gaya gambar. Bandingkan contoh visual dan baca tujuan setiap shorthand.
  2. Salin prompt lengkap. Buka detail dan salin instruksinya. Kode pendek saja tidak memiliki perilaku bawaan yang terjamin.
  3. Sesuaikan di ChatGPT Images. Ganti detail produk sesuai kebutuhan. Lampirkan foto jika ada, lalu kirim prompt untuk membuat gambar.

Contoh memakai cangkir biru fiktif tanpa merek. Hasil dapat berbeda saat prompt dijalankan ulang.
